<h2><a href="https://www.geeksforgeeks.org/problems/check-if-two-arrays-are-equal-or-not3847/1">Two Arrays Permutation Check</a></h2><h3>Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given two arrays <strong>a[]</strong> and <strong>b[] </strong>of equal size, the task is to find whether the given arrays are permutation of each other. </span><span style="font-size: 18px;">Two arrays are said to be permutation if both contain the same set of elements, arrangements of elements may be different though.</span></p><p><span style="font-size: 18px;"><strong>Note:</strong> If there are repetitions, then counts of repeated elements must also be the same for two arrays to be permutation.</span></p><p><span style="font-size: 18px;"><strong>Examples:</strong></span></p><pre><span style="font-size: 18px;"><strong>Input: </strong>a[] = [1, 2, 5, 4, 0], b[] = [2, 4, 5, 0, 1]

</span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>a[] = [1, 2, 5], b[] = [2, 4, 15]
