<h2><a href="https://www.geeksforgeeks.org/problems/make-zeroes4042/1">Process Zeros and Neighbors in Grid</a></h2><h3>Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a matrix <strong>mat[][]</strong>, </span>Your task is to do the following operations for every 0.</p><ul><li value="1">Replace the zero with the sum of upper, lower, left and right values</li><li value="2">Make its four adjacent (upper, lower, left, and right) values zero.</li></ul><p><span style="font-size: 18px;"><strong>Examples:</strong></span></p><pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] = [[1, 2, 3, 4], [5, 6, 0, 7], [8, 9, 4, 6], [8, 4, 5, 2]]
<strong>Output:</strong> mat[][] = [[1, 2, 0, 4], [5, 0, 20, 0], [8, 9, 0, 6], [8, 4, 5, 2]]
<strong>Explanation:</strong> As mat[1][2] = 0, we will perform the operation here. Then mat[1][2] = mat[0][2] + mat[2][2] + mat[1][1]  + mat[1][3] and mat[0][2] = matrix[2][2] = matrix[1][1] = matrix[1][3] = 0.</span>
</pre><pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input: </strong><span style="font-size: 18px;">mat[][] = [[1, 2], [3, 4]]
</span><strong style="font-size: 18px;">output: </strong><span style="font-size: 18px;">mat[][] = [[1, 2], [3, 4]]<br><strong>Explanation:</strong> As there is no zero in the matrix, no operation is performed and the matrix remains unchanged.</span></span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Matrix</code>&nbsp;
